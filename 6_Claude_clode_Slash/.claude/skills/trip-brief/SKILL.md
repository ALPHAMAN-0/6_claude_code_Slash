# Trip Brief

When formatting a travel recommendation, present the result as a **Trip Brief**
in exactly this structure:

## Trip Brief: <Destination>

- **Weather:** <one line>
- **Cheapest flight:** <price>, <date>
- **Verdict:** <one sentence — go / wait / reconsider, and why>

Rules:

- Keep the whole brief under 60 words.
- Always end with a clear Verdict. Never hedge.
- If any data point is missing, say so explicitly instead of guessing.
